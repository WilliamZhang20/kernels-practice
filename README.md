# Kernels Practice

A collection of GPU kernel experiments and supporting benchmarks, covering attention, normalization, softmax, convolutions, sampling, and transformer components.

## Contents

- CUDA kernels: `attention.cu`, `layernorm.cu`, `rmsnorm.cu`, `softmax.cu`
- Python experiments: `benchmark.py`, `maskedSelfAttention.py`, `conv2d.py`, `stupid_sampling.py`, `swiglu.py`, `topk.py`, `transformer.py`

These are practice and experimentation projects; see each source file for its implementation and usage details.
